# E-Commerce Customer Behaviour Analysis

A beginner-friendly Python project that analyses online shopping order data using pandas.

## Project Goal

Understand customer behaviour: what people buy, how much they spend, whether they return to shop again, and how delivery or order problems connect with customer feedback.

## Files

- `ecommerce_data.csv` – Sample dataset with 30 orders
- `analysis.py` – Main analysis script (answers all 8 investigation questions)
- `requirements.txt` – Python dependencies

## What It Answers

1. Total orders and total completed-order value and sales
2. Categories and cities contributing most to orders and sales
3. Proportion of customers placing more than one order
4. Average order value difference between customer groups
5. Rates of cancellation and return
6. Whether longer delivery durations appear with lower customer ratings
7. Customer segments with stronger repeat-purchase behaviour
8. Recommended actions to improve customer experience

## How to Run

```bash
pip install -r requirements.txt
python analysis.py
```

## Requirements

- Python 3.x
- pandas

## Beginner Notes

This project uses only Python and pandas. The code is short, simple, and commented so it is easy to understand and modify.
